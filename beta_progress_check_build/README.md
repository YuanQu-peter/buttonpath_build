# Beta progress check

[Play ButtonPath](https://yuanqu-peter.github.io/buttonpath_build/beta_progress_check_build/). Select **Play**, then **Level 1** to start from the beginning, or choose any of the seven levels to test it directly.

This WebGL build was published for the November 3, 2026 Beta progress check. It uses Unity 6000.3.22f1, the ButtonPath scene, and the ButtonPathTouch web template from [Team200 commit `80f2261`](https://github.com/Firemanwolf/Team200/commit/80f2261b29e0f857e8510b969463adaebd6429e7).

The [build manifest](build-manifest.json) lists the size and SHA-256 checksum of each game file.

Tested in desktop Chrome: the title screen loaded, the level selector showed Levels 1 through 7, and Level 1 opened with its first placement prompt.
